# A Jornada do Rafael - PWA

## Publicar gratuitamente
1. Extraia o ZIP.
2. Envie todo o conteúdo da pasta para um repositório no GitHub.
3. Publique com GitHub Pages, Netlify ou Vercel.
4. Abra o endereço HTTPS no Chrome do Android.
5. Toque em **Instalar app** ou no menu do Chrome > **Adicionar à tela inicial**.

O app calcula a idade gestacional com base na DPP de 09/03/2027, funciona offline após o primeiro acesso e compartilha pelo WhatsApp.
