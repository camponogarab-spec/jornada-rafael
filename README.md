# A Jornada do Rafael

Aplicativo PWA responsivo para acompanhar a gestação do Rafael, com atualização automática da idade gestacional, desenvolvimento semanal, compartilhamento pelo WhatsApp e música instrumental original com tema de natureza e safári.

## Publicação
Envie todos os arquivos desta pasta diretamente para a raiz do repositório `jornada-rafael`. O GitHub Pages publicará a atualização automaticamente a partir da branch `main`.
